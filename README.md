# The Twelve

An interactive companion for a 12-session small-group study of the twelve disciples — their history, personality, perspective, and contribution. Built to display on a living-room TV during discussion.

**Live page:** https://bushman1970.github.io/the-twelve/

- Tap any disciple to open his session panel
- `←` `→` move between disciples · `↑` `↓` toggle "The man" / "Talk it over" · `Esc` back to the map
- All Scripture quotations are ESV
